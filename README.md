# Edy-Tutor SPAN 107 (Habla)

Aplicación web interactiva de tutoría oral y comunicativa en español desarrollada con **Streamlit** y **Gemini**, diseñada para estudiantes del curso SPAN 107.

## Características principales
- **Práctica guiada e interactiva:** Apoyo en la adquisición de la segunda lengua enfocado en la interacción comunicativa.
- **Integración con Google Sheets:** Almacenamiento y consulta de registros a través de conectores seguros.
- **Ejecución local y segura:** Soporte para funcionamiento offline o mediante credenciales protegidas (`secrets.toml`).
